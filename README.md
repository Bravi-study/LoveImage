# LoveImage

Два фото и пожелание на входе, совместный романтический снимок на выходе. Личный кабинет с историей.

## Запуск

Нужен только Docker.

1. Скачай репозиторий:

   ```bash
   git clone https://github.com/Bravi-study/LoveImage.git && cd LoveImage
   ```

2. Положи в его корень файл `.env`, полученный от владельца. В git его нет и быть не должно: репозиторий публичный.
3. Запусти. Первая сборка может занять несколько минут:

   ```bash
   docker compose up --build app worker
   ```

4. Открой http://127.0.0.1:8000.

Каждый снимок тратит 10 кредитов kie.ai. Остановить сайт: Ctrl+C, данные сохранятся.

Как устроено, как разрабатывать и как развернуть на сервере: [AGENTS.md](AGENTS.md). Контракт API: [docs/design.md](docs/design.md).

Все люди в `web/public/examples/` выдуманы и созданы генератором.
